# BigCoach Anki Studio

BigCoachの解析結果をアプリ内で表示し、現在局面の取得、何切るシミュレーション、比較表示、Ankiカード登録を一つのWindowsアプリで行います。

## 利用者向け

1. `BigCoach Anki Studio`を起動します。
2. 左側のBigCoachで通常通り牌譜を開き、解析します。
3. 右側の「局面を取得」を押します。
4. 「何切るシミュレーターを実行」を押します。
5. 必要ならメモを書き、「カード内容をプレビュー」からAnkiへ登録します。

「前の局面」「次の局面」は、何切るを実行できる自家の打牌判断局面だけを順に移動します。「大悪手一覧を表示」を押すと、解析結果全体から大悪手を列挙し、任意の項目をクリックして直接移動できます。

「前／次のミス」「前／次のシン悪手」「前／次の大悪手」は、対象局面を事前に抽出して直接移動します。移動時はBigCoachのiframeを再読込せず、読込済みの解析データを使って表示だけを更新します。

解析済みURLを右パネルへ貼り付けると、その結果を直接開けます。開いたURLは最大50件の履歴として保存されます。

Anki登録には、AnkiとAnkiConnectアドオン（コード `2055492159`）が必要です。アプリの「診断」で接続状態、デッキ名、ノートタイプを確認できます。

Ankiへの表裏画像・牌画像は、AnkiConnectが処理しやすいよう1件ずつ送信します。Ankiの同期中などで画像転送がタイムアウトした場合は、接続エラーと区別して対象処理を表示します。

## 局面取得について

BigCoachの画面DOMから、手牌、河、副露、ドラ、局情報、点数、AI候補を取得します。取得できなかった項目は操作パネルに明示します。BigCoachのUI変更で取得不能になった場合は「詳細ログ」と診断情報を確認してください。

BigCoachがモダンUI形式の解析結果を返した場合、局面取得時に自動でクラシックUIへ切り替えて解析データを取得します。

シン悪手の定義は、次の条件局面で実打とBigCoach推奨が異なり、実打のAI推奨度が設定値以下（初期値 `0.001` = `0.1%`）となる判断です。BigCoach画面の `41.5` は内部値 `0.415`（41.5%）として扱います。

- 2シャンテン以下または聴牌
- 他家がリーチしている
- 自分のリーチ後は除外。ただしリーチした瞬間は含む

大悪手は、1シャンテン以下・聴牌・他家リーチ時のいずれかで、実打とBigCoach推奨が異なり、実打のAI推奨度が設定値以下となる判断です。推奨度上限はシン悪手と共通です。

シン悪手率は「シン悪手回数 ÷ 条件対象回数」です。解析した各局について4人全員の配牌から一意キーを生成し、同じ局を再解析しても通算結果へ重複加算しません。

シン悪手率欄には、解析日時順の「各解析」と「通算」の推移グラフを表示します。同じ配牌構成の解析を再度読み込んでも、グラフと通算値へ重複追加しません。

## Ankiカード画像

- 表面: 問い（何切？／副露？／リーチ？）を最上部に表示し、何切モード、他家手牌非表示、卓と自家手牌
- 裏面: メモを最上部に表示し、何切モード解除、他家手牌表示、BigCoach全体画面
- 裏面画像直下: 流局・横移動・放銃・和了の各確率
- 裏面下部: 何切るシミュレーターの比較結果

カードプレビュー時にシミュレーターが未実行なら、自動実行します。

### 何切る悪手カード

次の条件をすべて満たす局面を「何切る悪手」として扱います。

- 実打とBigCoach推奨打牌が異なる
- 手牌に不要牌がない
- 他家がリーチ・副露していない
- 2シャンテン以下
- BigCoach推奨、河の既知牌を残り枚数から除いたシミュレーター推奨、補正しないシミュレーター推奨の3つが一致

不要牌は、同種1枚だけの孤立字牌、または同種1枚だけで同じ色の±1・±2の牌がなく、実ドラでもない数牌です。赤5は通常の5と同種として判定します。不要牌が1枚だけ存在し、その牌がBigCoach推奨打牌である場合は、例外として何切る悪手の対象に含めます。不要牌が2枚以上ある場合や、唯一の不要牌とは別の牌が推奨されている場合は対象外です。

判定は「実打間違い → 不要牌 → シャンテン数 → シミュレーター」の順で行います。局面が何切る悪手なら通常デッキには登録せず、設定した「何切る悪手デッキ」に平面何切るカードだけを登録します。

平面カードの表面には手牌、副露、ドラ表示牌、巡目、場風、自風を表示します。裏面には正解、3種類の推奨、mpsz、加工用JSON、BigCoach参考画像、解析URL、局面IDを保存します。通常カードとは別の重複キーを使います。

何切る悪手カードの裏面には、補正無（河・副露を残り枚数へ反映しない）シミュレーターの候補別結果も表示します。各候補の打牌、期待値、和了率、聴牌率、受入牌を牌画像付きで保存します。

「前の何切る悪手」「次の何切る悪手」は、指定方向にある局面から、打牌ミス・他家リーチなし・2シャンテン以下を先に絞ります。巡目による制限はありません。局面移動後に他家副露なし・不要牌条件を確認した候補だけシミュレーターへかけ、最初に見つかった対象へ直接移動します。判定済み局面は現在の解析URLについてキャッシュされます。未探索の方向へ進む場合は、新しい候補だけ追加で判定します。

「何切る悪手を一括でデッキに登録」は現在の解析結果に含まれる候補を順に判定し、何切る悪手専用デッキへ未登録カードだけを追加します。進捗と追加・重複・失敗件数は右パネルに表示します。

前後のシン悪手・大悪手移動では、何切る悪手の高速事前条件に入る局面を保守的に除外します。移動のたびに追加シミュレーションを行わないため、実際の何切る悪手が混ざらず、操作速度も維持されます。

専用カードの表面は、場風・自風・巡目・ドラ表示牌を手牌より上に表示します。手牌は牌画像を横方向に結合した1枚のSVG画像として保存するため、途中で改行されません。

カード撮影前には、内部設定値ではなく実際のDOMを確認します。問題面はAI棒グラフがなく相手手牌がすべて裏向き、解答面はAI棒グラフがあり相手手牌が表向きになった場合だけ撮影します。条件を満たせない場合はカードを作らずエラーを表示します。

DOM確認後はブラウザの複数描画フレームとElectronのコンポジタ反映を待ち、同じDOM状態が連続して確認できた場合だけ画像を撮影します。

局面移動UIは右パネル上部の「診断」「設定」の直下に表示します。

解析済みURLを開くと、シン悪手率を自動計算します。計算・局面移動はBigCoach画面に読み込まれたデータを参照し、追加の解析API呼び出しや定期的な外部通信は行いません。

## 開発・ビルド

```powershell
npm.cmd install
npm.cmd test
npm.cmd run start
npm.cmd run dist
```

`resources/simulator`にはmahjong-cpp `nanikiru.exe`の実行に必要なファイルを配置します。配布版はこのディレクトリを同梱し、アプリがバックグラウンドで自動起動します。

## 技術上の注意

- BigCoachの認証状態はElectronの永続セッション `persist:bigcoach` に保存されます。有効期限なしのログインCookieもWindows DPAPIで暗号化保存し、次回起動時に復元します。ログアウトした場合は保存内容も更新されます。
- 何切る結果は、画面上の既知牌を残り牌から除いた結果と、補正しない結果を並べて保持します。
- 重複判定は局面情報から生成した局面IDをAnkiタグへ保存して行います。
- BigCoachそのものや解析AIは再実装していません。
