# BigCoach Anki Studio

BigCoachの解析結果をアプリ内で表示し、現在局面の取得、何切るシミュレーション、比較表示、Ankiカード登録を一つのWindowsアプリで行います。

## 利用者向け

1. `BigCoach Anki Studio`を起動します。
2. 左側のBigCoachで通常通り牌譜を開き、解析します。
3. 右側の「局面を取得」を押します。
4. 「何切るシミュレーターを実行」を押します。
5. 必要ならメモを書き、「カード内容をプレビュー」からAnkiへ登録します。

「前の局面」「次の局面」は、何切るを実行できる自家の打牌判断局面だけを順に移動します。「大悪手一覧を表示」を押すと、解析結果全体から大悪手を列挙し、任意の項目をクリックして直接移動できます。

「前／次のミス」「前／次のシン悪手」「前／次の大悪手」は、対象局面を事前に抽出して直接移動します。移動時はBigCoachのiframeを再読込せず、読込済みの解析データを使って表示だけを更新します。

解析済みURLを右パネルへ貼り付けると、その結果を直接開けます。開いたURLは最大50件の履歴として保存されます。

Anki登録には、AnkiとAnkiConnectアドオン（コード `2055492159`）が必要です。アプリの「診断」で接続状態、デッキ名、ノートタイプを確認できます。

## 局面取得について

BigCoachの画面DOMから、手牌、河、副露、ドラ、局情報、点数、AI候補を取得します。取得できなかった項目は操作パネルに明示します。BigCoachのUI変更で取得不能になった場合は「詳細ログ」と診断情報を確認してください。

シン悪手の定義は、次の条件局面で実打とBigCoach推奨が異なり、実打のAI推奨度が設定値以下（初期値 `0.001` = `0.1%`）となる判断です。BigCoach画面の `41.5` は内部値 `0.415`（41.5%）として扱います。

- 2シャンテン以下または聴牌
- 他家がリーチしている
- 自分のリーチ後は除外。ただしリーチした瞬間は含む

大悪手は、1シャンテン以下・聴牌・他家リーチ時のいずれかで、実打とBigCoach推奨が異なる判断です。

シン悪手率は「シン悪手回数 ÷ 条件対象回数」です。解析した各局について4人全員の配牌から一意キーを生成し、同じ局を再解析しても通算結果へ重複加算しません。

## Ankiカード画像

- 表面: 問い（何切？／副露？／リーチ？）を最上部に表示し、何切モード、他家手牌非表示、卓と自家手牌
- 裏面: メモを最上部に表示し、何切モード解除、他家手牌表示、BigCoach全体画面
- 裏面画像直下: 流局・横移動・放銃・和了の各確率
- 裏面下部: 何切るシミュレーターの比較結果

カードプレビュー時にシミュレーターが未実行なら、自動実行します。

解析済みURLを開くと、シン悪手率を自動計算します。計算・局面移動はBigCoach画面に読み込まれたデータを参照し、追加の解析API呼び出しや定期的な外部通信は行いません。

## 開発・ビルド

```powershell
npm.cmd install
npm.cmd test
npm.cmd run start
npm.cmd run dist
```

`resources/simulator`にはmahjong-cpp `nanikiru.exe`の実行に必要なファイルを配置します。配布版はこのディレクトリを同梱し、アプリがバックグラウンドで自動起動します。

## 技術上の注意

- BigCoachの認証状態はElectronの永続セッション `persist:bigcoach` に保存されます。
- 何切る結果は、画面上の既知牌を残り牌から除いた結果と、補正しない結果を並べて保持します。
- 重複判定は局面情報から生成した局面IDをAnkiタグへ保存して行います。
- BigCoachそのものや解析AIは再実装していません。
