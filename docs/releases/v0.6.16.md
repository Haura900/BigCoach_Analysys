# BigCoach Anki Studio 0.6.16

- 共通エンジンを 0.9.15 に更新。既知牌を引いた残り枚数から経過巡目を再度引いていた期待値計算を修正。
- 山河反映の赤5の内数表現、赤なし設定、重複する既知牌の検証を修正。
- 赤5と普通の5の期待値比較・鳴きで消費する手牌・河から副露への牌の移動・加槓を修正。
- 河のJSON形式によって既知牌が欠けるフォールバックを修正。
- 自分の3m暗槓がある12m形で、山河反映時の3mが残り0枚になることを確認。

78件のアプリ単体テストと、Windows版の実局面入力で確認済み。旧版とは期待値の数値が変わります。未知牌プールによる近似計算のため、不要牌を除くことで有効牌の割合が上がり、期待値が上がる場合自体は正常です。
