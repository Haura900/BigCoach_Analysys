HOW IT WORKS

評価方法

p

AIの予測

BigCoach JSONに含まれる和了確率・放銃率・期待打点だけを使用します。

Y

実際の結果

和了・放銃なら1、そうでなければ0。打ち方の良し悪しとは分離します。

σ

偶然の偏り

予測との差を分散で標準化。|2σ|を超えるほど珍しい偏りです。
